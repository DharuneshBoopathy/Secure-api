API Security Monitor — setup
============================

Local Development
-----------------

1) Start platform services:
   docker compose up -d

2) Install backend:
   py -3 -m pip install -r requirements.txt
   copy .env.example .env

3) Run API:
   uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

4) Run UI:
   cd frontend
   npm install
   npm run dev

5) Optional seed data:
   py -3 scripts/seed_demo.py

6) Validate:
   - http://127.0.0.1:8000/health
   - http://127.0.0.1:8000/docs
   - http://127.0.0.1:5173

Production
----------

1) Set all required env vars in `.env`:
   DATABASE_URL, MONITOR_API_KEY, SECRET_KEY, ADMIN_USERNAME, ADMIN_PASSWORD,
   JWT_ALGORITHM, ACCESS_TOKEN_EXPIRE_MINUTES, REFRESH_TOKEN_EXPIRE_DAYS, CORS_ORIGINS

2) Start production stack:
   docker compose -f docker-compose.prod.yml up --build -d

3) Validate:
   - /health returns 200
   - /docs loads
   - Grafana and Prometheus are reachable on internal/allowed network

Testing
-------

Backend:
   py -3 -m pytest

Frontend:
   cd frontend
   npm run test
   npm run build

Notes
-----

- Use JWT auth for UI users.
- Keep X-Monitor-Key for automation scripts only.
- Do not expose `/metrics` publicly.
